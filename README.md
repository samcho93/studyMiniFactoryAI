AI 가 화면 밖으로 나와 공장 설비를 보고 · 판단하고 · 움직이는 시대 — **제조 AI** 와 **피지컬 AI** 를
스마트 미니팩토리 통합 플랫폼을 직접 사용하며 익히는 강좌입니다. **코드를 배우는 강좌가 아닙니다.**

- **도입(1~3차시)**: 제조 AI 가 왜 필요한지와 전망, 피지컬 AI 의 정의(**로봇만이 아니다**), 피지컬 AI · 제조 AI · 이 플랫폼의 관계
- **플랫폼 시작(4~5차시)**: 설치 · 첫 실행 · 화면, 공장 라인과 3D 디지털트윈 운전
- **ERP · MES(6~10차시)**: 기준정보 · 수주 → 생산계획 · 생산오더 → 자재 · 구매 · 재고 · 출고 → 작업지시 · 실적 → 품질 · LOT · 대시보드
- **AI 로 일하기(11~14차시)**: AI 예지보전(데이터 · 이상 탐지 · 알람), 가상 고장과 AI 진단 · 정비 권고, AI 생산계획(말로 계획 세우기), AI 도우미와 AI 키
- **현장 사례(15~17차시)**: 급주문 · 자재 부족 · 다색 소량 · 설비 증설 · 납기 지연 · 주간 계획 / 컨베이어 고장 · 델타 흡착 · 에어 · 안전 도어 · 품질 불합격 · 교대 보고 / 하루 공장 운영 종합 미션

모든 교시는 **화면 캡처를 보며 단계마다 따라 하고 ☑ 완료를 체크하는 단계별 실습**(진행률 저장)과 퀴즈로 구성됩니다.

## 로컬에서 보기

```bash
python server/serve.py --port 8080        # Windows: start.bat (같은 네트워크 학생에게: start-lan.bat)
```

실습 프로그램(miniPythicalAI)은 강사에게 받은 폴더의 `run.bat` 으로 실행합니다(4차시).
